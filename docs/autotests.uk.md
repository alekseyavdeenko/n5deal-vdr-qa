## Код фреймворку (`src/`)
| Файл | Що це |
|---|---|
| `src/api/client.ts` | По одній функції на кожен ендпоінт API, нею користуються всі API-тести |
| `src/api/contract.ts` | Порівнює кожну відповідь API з документацією API |
| `src/fixtures.ts` | Готові користувачі після входу (власник, другий користувач, анонім) і нова порожня папка для кожного тесту |
| `src/ui/fixtures.ts`, `src/ui/pages/` | Сторінки браузера для E2E-тестів (page objects) |
| `src/data/factory.ts` | Унікальні назви і справжній PDF, створений у пам'яті |
| `src/reporters/known-bugs-reporter.ts` | Блок "Known bugs" наприкінці прогону |
| `global-setup.ts`, `global-teardown.ts` | Створюють папку прогону перед тестами й видаляють її після |
